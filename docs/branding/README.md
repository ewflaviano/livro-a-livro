# Marca para o consentimento Google

`google-consent.svg` combina o símbolo existente em `public/icons/book.svg` com o nome Livro a Livro e as cores do design system. `google-consent.png` é a exportação quadrada de 512 × 512 pixels para o campo **App logo** da seção Branding do projeto Google `livro-a-livro`.

O ícone não altera o manifesto nem o símbolo da PWA. O PNG foi renderizado sem rede a partir do SVG e conferido visualmente. A aprovação da marca pelo Google é separada do status de publicação do consentimento.
