# Segurança e privacidade

Se encontrar uma falha que possa expor livros, notas, avaliações, capas, backups, tokens ou credenciais, **não abra uma issue pública**. Envie um relato para [ewanderson.flaviano@gmail.com](mailto:ewanderson.flaviano@gmail.com) com passos para reproduzir usando dados fictícios. Não envie sua biblioteca, arquivos de backup ou dados de outra pessoa.

Problemas comuns de interface e comportamento podem ser relatados nas [issues](https://github.com/ewflaviano/livro-a-livro/issues). Evite anexar capturas ou logs que mostrem dados pessoais.
